# B站字幕摘录(bili-sub-recorder)

刷B站时听到有意思的内容,按快捷键开始/停止摘录视频字幕,一键复制语录,不用再手打。

Chrome / Edge 通用(Manifest V3),纯原生实现,零依赖、零构建,数据全部存本地。

## 功能

- **快捷键摘录**:默认 `Alt+X` 开始/停止,可在弹窗里录制任意组合键;输入框里打字不会误触(纯按键忽略,组合键仍可用)
- **只记录听到的**:按播放进度实时捕获字幕行——回拖不重复,跳过的段落只在真正播放到时才收录
- **浮窗**:记录中显示「记录中 · N 句 · M 字」;停止后展开语录卡片,可滚动查看、直接编辑,复制的就是编辑后的内容
- **自动归档**:每条记录自动带视频标题、UP主、链接;记录中切视频/分P会自动停止并保存
- **历史记录**:点扩展图标查看,最新在前;每条语录可直接编辑(自动保存,标注「已编辑」);全文可滚动;逐条复制/删除/清空;未编辑的记录复制文本可切换「带时间戳」
- **换电脑迁移**:弹窗底部「导出」下载 JSON 文件,新电脑上「导入」即可;按记录 id 去重合并,重复导入不会产生双份
- **编辑自动保存**:浮窗或弹窗里的修改都写入本地记录(输入约 0.6 秒后自动落库,复制/收起时立即落库),两处内容保持一致
- **本地存储**:`chrome.storage.local`,上限 500 条,超出自动删最旧

## 安装

1. 打开 `chrome://extensions/`(Edge 是 `edge://extensions/`)
2. 右上角打开「开发者模式」
3. 「加载已解压的扩展程序」→ 选择本目录(`bili-sub-recorder/`)
4. 工具栏出现粉色图标即成功;以后改了代码,在这里点「重新加载」+ 刷新页面生效

## 使用

1. 打开B站视频页(`www.bilibili.com/video/BV...`),右上角出现「摘录」小圆钮
2. 听到想保存的话 → `Alt+X` 开始 → 讲完再按 `Alt+X` 停止
3. 展开的语录卡片里可滚动、直接修改文字 → 点「复制全部」,复制的就是编辑后的内容
4. 点扩展图标管理历史:每条语录可直接编辑(自动保存)、单条复制/删除、清空全部、录制新快捷键、切换时间戳格式

## 换电脑迁移(导入 / 导出)

- **导出**:扩展弹窗底部点「导出」→ 下载 `bili-sub-recorder-日期.json`(包含全部记录:原文/编辑后内容/视频信息/字幕时间轴)
- **导入**:新电脑上装好扩展后,点「导入」选择这个 JSON 文件 → 按记录 id 去重合并,提示"解析 N 条,新增 M 条"
- 重复导入同一份文件是安全的(不会产生双份);导入只做合并,不会覆盖或删除已有记录;清空后再导入即可实现"整库搬迁"

## 字幕来源与限制

按两条通道取字幕,取到为准:

1. 拦截播放器自己的字幕请求(wbi 签名由页面完成,最稳)
2. 直接请求 `/x/player/v2` 接口兜底(2026-10 实测仍可用)

字幕轨优先 UP 主上传的 **CC 字幕**,其次 **AI 字幕**。

- **未登录B站时接口不返回任何字幕**(CC/AI 都如此,2026-10 实测)——使用前请先登录
- 视频本身没有字幕时无法摘录,浮窗会明确提示
- 只支持普通视频页;番剧/直播/课程页、互动视频、充电专属视频未适配
- 已编辑的记录以你的文字为准,不受「带时间戳」开关影响(开关只作用于未编辑的记录)

## 目录结构

```
manifest.json        MV3 配置(MAIN world 钩子 + isolated 主脚本,见下方"注入结构"说明)
content/core.js      纯逻辑(单测对象):字幕匹配/收集/快捷键/格式化/编辑落库/存储裁剪
content/hook-main.js MAIN world 拦截播放器字幕请求(自包含,不依赖 core.js)
content/content.js   状态机 + 浮窗 UI + 实时收集 + 存储
content/content.css  浮窗样式
popup/               历史记录 + 设置弹窗
icons/               扩展图标
```

> **注入结构注意**:`core.js` 必须只出现在 isolated 条目里。若同一个文件同时列在 MAIN 和 isolated 条目,内核会把它归并到先注入的世界,导致隔离世界拿不到 `BiliSubCore`(0.1.0 版曾踩过这个坑)。

## 故障排查

- **浮窗不出现**:确认已在 `chrome://extensions` 启用并(改码后)点过「重新加载」,且刷新了B站页面;控制台若报 `core.js 未注入`,重新加载扩展即可
- **提示"没有可用字幕"**:先确认浏览器已登录B站;仍未解决则是该视频确实没有字幕轨
- **快捷键没反应**:焦点在输入框/文本域里时,纯按键(打字)不会触发快捷键,属防误触设计——带 Ctrl/Alt/Meta 的组合键不受影响;也可直接点浮窗圆钮切换
